# Booking Card (React + Vite)

## Run
    npm install
    npm run dev        # open the URL shown (usually http://localhost:5173)

## Build
    npm run build

## Pop-out images
public/boat.svg, wave.svg, stone.svg, tent.svg, bush.svg are transparent (no background).
To use your own PNG, put it in public/ (e.g. boat.png, transparent background) and change
the src in src/components/BookingCard.jsx.
